## About

I build and maintain backend systems: HTTP APIs, background jobs and the
infrastructure that runs them. Most of my work is in **Python** (FastAPI, Django)
and **.NET**, deployed on **AWS** — often serverless, always with CI/CD and
containers around it.

I care about the parts that show up six months later: clear boundaries between
layers, tests that catch real regressions, and deployments that are boring to run.

## What I do

- **APIs and services** — design and build REST APIs with FastAPI, Django and
  .NET, with a clean separation between transport, domain logic and persistence.
- **Serverless on AWS** — event-driven workloads on Lambda and managed services,
  sized to keep cost and cold starts predictable.
- **CI/CD and automation** — GitHub Actions pipelines that lint, test, build
  containers and deploy, so releases don't depend on anyone's laptop.
- **Data layer** — relational modelling on PostgreSQL and MySQL: schema design,
  migrations, and queries that stay fast as tables grow.
